# Engineering InfoBot

Engineering InfoBot is a college recommendation system that helps students identify suitable engineering colleges based on their academic performance. The application uses Machine Learning to analyze student percentages and provide college recommendations through an interactive chatbot interface.

## Overview

Choosing the right engineering college can be challenging for students after examinations. Engineering InfoBot simplifies this process by analyzing student scores and suggesting colleges that match their academic performance.

The system uses a Linear Regression model for prediction and presents recommendations in a simple and understandable format through a chatbot interface.

## Features

* College recommendation based on student percentage
* Machine Learning-based prediction using Linear Regression
* Interactive chatbot interface
* User-friendly web application

## Technologies Used

* Python
* Flask
* HTML5
* CSS3
* JavaScript
* Scikit-learn
* Linear Regression
* OpenAI GPT-4o Mini API

## How It Works

1. The student enters their academic percentage.
2. The Linear Regression model analyzes the input.
3. Suitable colleges are predicted based on the trained dataset.
4. The recommendation is displayed through the chatbot interface.
